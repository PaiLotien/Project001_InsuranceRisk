## 一句话结论

- **主数据集：巴西 SUSEP AUTOSEG 车险统计。** 它有真实的"州 × 车型/品牌 × 车龄 × 驾驶人"维度，带暴露（车年）、保费、赔案件数和赔款，是唯一同时具备**区域 + 车型 + 保费 + 赔款**的公开车险数据。CASdatasets 的 `brvehins1` 是 2011 年全量版本，已下载。用它跑 IRDS 主表的 PoC 已经成功：IRDS 现有解析器校验通过，预警分布为正常 161、黄 57、红 31。
- **时间维度**：SUSEP 官网从 2006 年下半年起每半年发布一期（至少到 2021 年），可以形成十几年的半年度真实序列。但 box 的出网被拦（TLS 被重置），**需要在你电脑或别的网络上下载**。
- **辅助集：西班牙真实车险组合（Mendeley，CC BY 4.0）。** 有 2015–2018 年的续保日期、保费、赔款和 4 类车型，适合演示"时间趋势 + 赔款进展（未成熟年度赔付率偏低）"。已下载。
- **中国口径校准**：用金融监管总局的分省保费、全国车险保费和赔付，中保协和精算师协会披露的车险综合费用率、赔付率、车均保费、新能源车险赔付情况，再加上已确认的 BR-046 频度基准，来校准一层"中国分公司合成层"。合成部分必须标注"合成"。
- **给渤海的问题清单**：共 **46 题**，其中必问 28 题，只问一轮时可以压缩到 24 题。已经和《业务规则汇总表_全量》中 136 条 BR 规则（其中已确认的大部分）去重，只问"建议待确认/推断内容"和问卷没覆盖到的部分。全部是**不需要给原始数据**就能回答的指导类问题。

### A4. 已核实的数据坑（PoC 中已处理）

1. **brvehins 的法人保单赔案错位。** 标为 Corporate 的行有暴露和保费，但赔案件数恒为 0；性别缺失、暴露为 0 的行带着赔案，占赔款的 15.4%。PoC 把后者并回同州同车型的"企业车"，并回后企业车赔付率 71.6%，量级合理。这是**假设**，已写在脚本注释里。
2. **2011 年 brvehins 的经验赔付率是 63.4%。** 出险频度 23.7%/车年，案均 3,129 雷亚尔，每车年保费 1,171 雷亚尔。巴西 CASCO（车损）频度明显高于国内家用车的 6–10%（BR-046），所以**不能把巴西的绝对值当中国基准**，只用它的结构和波动。
3. **西班牙数据的赔款不成熟**：最近年度的赔付率被严重低估。适合演示"满期进展、同进展期才可比"（BR-123），不适合直接拿来判断趋势。

## A5. 推荐方案和映射计划

### 主数据集：SUSEP AUTOSEG（先用 brvehins1 跑通，再换成多学期原始文件补时间）

**为什么选它**：
- 维度最全：区域（27 州，可下钻到 40 个区域和 3,417 个城市）对应"机构"（IRDS 要求 ≥20 家，BR-008 说的是约 24 家省级机构）；车型和品牌对应"车型"。
- 指标最全：保费、暴露、件数、赔款四项都有，能直接算 IRDS 的四个核心指标（赔付率、出险频度、案均赔款、单均保费）。
- 量大而且真实：约 200 万个汇总格，来自全市场；许可明确。
- 多学期原始文件补上时间维度后，可以做同比、环比、漂移检测和 BR-048 的"当年 > 上年同期就标红"。

### IRDS 期望的输入格式（读自 `src/parser/upload_data.py`、`src/validation/data_contract.py`、`data/sample/demo_dataset.xlsx`）

- 优先读取名为"完整数据集"或"主表"的 Sheet；也接受 CSV。
- 必需字段：`车型`；至少要有 `预期成本率` 或 `预期赔付率` 中的一个（取值 0–200）。
- 常用字段：`机构`、`保费占比`（0–100，每个机构的各车型合计约 100）、`签单保费_万元`、`预期赔付率`、`成本率1`、`预期成本率`、`自主定价系数`、`单均保费_元`、`累计出险频度`、`数据口径`、`统计日期`；每个机构都要有一行"合计"。
- 去重键：统计日期、机构、车型（如有，再加能源类型和期间）。预警由 `apply_alert_rules`（读 `config/alert_rules.yaml`）自动计算。

### 字段映射（brvehins / AUTOSEG → IRDS 主表）

| IRDS 字段 | 计算方法 | 来源标记 |
|---|---|---|
| 机构 | 州（StateAb）→ 中文州名，再加"全辖"；如需地市级，用 brvehins2 的 City 或 AUTOSEG 的 cidade 表 | 真实 |
| 车型 | Corporate → 企业车；VehGroup 含 "Caminhões" → 货车；含 "Motos" → 摩托车（按 450cc 分为两个细分）；S-10、Hilux、Strada 等皮卡 → 非营业皮卡；其余 → 家用车，并按车龄细分为 0–2 年、3–7 年、8 年以上（对应《车型风险维度映射表》中 PC-004"车龄 ≥ 8 年"）。用多学期 AUTOSEG 时，改用官方的"费率类别"字段，更规范 | 真实（映射） |
| 签单保费_万元 | Σ PremTotal ÷ 1e4（单位是万雷亚尔；如需人民币，按当年平均汇率换算并在页面注明） | 真实 |
| 保费占比 | 车型保费 ÷ 本机构合计行保费 × 100 | 真实 |
| 单均保费_元 | Σ PremTotal ÷ Σ ExposTotal（每车年）。IRDS 的口径是每张保单（BR-029），两者差在年化方式上，页面需注明 | 真实 |
| 累计出险频度 | Σ 赔案件数 ÷ Σ 车年 × 100 | 真实 |
| 案均赔款 | Σ 赔款 ÷ Σ 赔案件数 | 真实 |
| 满期赔付率（新增字段） | Σ 赔款 ÷ Σ 保费 × 100（AUTOSEG 的保费按暴露期计，接近已赚口径） | 真实 |
| **预期赔付率** | 在汇总格上拟合频度 GLM（Poisson）和案均 GLM（Gamma），特征为州、车型、年龄段，得到每格的预期赔款；再按 BR-036/037 用"Σ预期赔款 ÷ Σ签单保费"保费加权计算。这正是 metric_definitions 中"基于保单级精算模型的预期赔付率"在公开数据上的替身。多学期时用上一期模型预测下一期，更接近真实的"预期" | 模型 |
| 成本率1 | 公开数据没有。按车型设参数（PoC 暂用 24–30%，量级参照中保协公布的车险综合费用率约 27%），之后用保险公司给的区间替换（见 B 组问题 D3） | 假设 |
| 预期成本率 | 预期赔付率 + 成本率1（BR-018） | 模型 + 假设 |
| 自主定价系数 | 公开数据没有。可选做法：用"实际保费 ÷ GLM 纯风险保费"做相对价格指数，归一到全辖均值为 1，并截断到监管区间 [0.5, 1.5]，标为"推导值"；或者先留空（IRDS 允许缺失） | 推导 / 留空 |
| 统计日期 / 期间 | brvehins：2011-12-31，期间"当年"；AUTOSEG 多学期：每学期末，可用学期差分得到半年"当期" | 真实 |
| 数据口径 | "保险起期（车年暴露）" | 说明 |
| 数据来源（新增字段） | "SUSEP AUTOSEG / CASdatasets"，加一个"字段来源说明"Sheet，标出真实、模型、假设 | 说明 |

### 辅助集用法
- **西班牙组合**：演示"按保单年度和月份的时间序列 + 渠道维度 + 赔款进展"。车型映射为：1 → 摩托车，2 → 营业 2 吨以下（厢式货车），3 → 家用车，4 → 特种车（农用）；机构只有两档（城市/农村），可以作为"示例机构"或只看全辖。
