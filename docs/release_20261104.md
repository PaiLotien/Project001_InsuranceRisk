# IRDS 团队测试包 2026-11-04

本轮按用户提供的代码示例调整八个业务模块：

- `src/alerts/thresholds.py`：展开校验状态判断、规则查找及空机构检查。
- `src/attribution/evidence.py`：使用直接的大小比较和结果赋值。
- `src/rules/rule_engine.py`：显式筛选同口径数据，展开前置条件判断，去除两个仅用于简单查询的嵌套函数。
- `src/validation/data_contract.py`：显式收集缺失字段及可用指标，精简重复说明。
- `src/validation/cross_report.py`：逐项筛选当月保费、分步求和、顺序查找双层表头。
- `src/monitoring/history.py`：展开字段缺省处理，为加权平均保留独立的保费总额和加权和变量。
- `src/monitoring/drift.py`：按数值、类别分别处理，展开多层条件表达式。
- `src/llm_advisor.py`：逐项准备输入，展开请求体和返回值读取步骤。
