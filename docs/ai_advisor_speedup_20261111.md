## 改了什么

1. **线程**：Ollama 模型默认只用 4 线程，改为 `num_thread: 8`（全部物理核），预填充约快一倍。
2. **固定 system 前缀**：Skill 作为 system 消息且与问题、模式无关（JSON 指令移到 user 消息末尾），Ollama 复用前缀 KV 缓存；启动时后台预热（`start_warmup`）一次把模型和前缀载入。
3. **缩短输出**：Skill 精简（3268→约 2600 字节），要求 150 字以内、不超过 3 条要点；JSON Schema 加 `maxItems`（依据 3、建议 3、待核查 2），由语法约束强制。
4. **上下文**：`top_k` 5→4，系统结果 JSON 紧凑序列化，`num_ctx` 8192→4096，`keep_alive: 2h`，`num_predict` 600→450。
5. **答案缓存**：`src/advisor/cache.py`，SQLite `data/runtime/advisor_cache.db`。键 = 规范化问题 + 系统数据指纹 + 知识库索引版本 + Skill 版本 + 模型 + 模式 + 检索参数；任何一项变化自动失效，重建索引时清理旧版本条目。带历史的多轮对话不走缓存；有无效引用或无法溯源数字的回答不缓存。看板“管理员”折叠区显示缓存条数，可一键清空。
6. **偶发 500 重试**：本机 Ollama 推理进程偶发重启（内存紧张时）返回 500，尚未输出内容时自动重试一次。
