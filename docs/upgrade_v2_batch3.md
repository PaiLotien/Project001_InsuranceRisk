# upgrade/v2 第 3 批：正式版界面与公开数据接入

## 1. 界面结构

- 页面配置标题“车险智能风控平台”；页头为产品名、副标题“IRDS · Insurance Risk Dynamic Surveillance”、当前数据集与期间、数据来源。
- 视觉规范集中在 `src/dashboard/theme.py`：深石板蓝页头 + 墨绿强调色、浅色内容区、细分割线；中文系统字体栈，数字等宽（tabular figures）；隐藏 Streamlit 菜单、部署按钮与水印；不引用任何外部字体或 CDN。自定义组件自带背景与文字色，浅色、深色主题均可读。
- 侧栏导航（9 个栏目）：

| 栏目 | 内容 |
|---|---|
| 监测总览 | 7 张 KPI 卡（全辖预期赔付率 / 成本率、红橙黄预警、待处置、数据质量问题）、风险等级分布、地区风险排行（上传中国机构数据时为省级地图）、重点关注 TOP10、一键导出 / 打印版、经营趋势与历史快照、指标口径 |
| 预警中心 | 预警清单（等级 / 地区筛选、排序、克制色标、触发规则列、机构与车型排行）、指标明细、统计异常（单列，标明“不改变预警等级”）、批量通知 |
| 归因分析 | 定量归因（对标全辖）：赔付率三要素对数分解（瀑布图，注明三项之和＝总变化）、结构 / 自身效应、Adtributor 异常切片 TOP N；下方保留单条预警规则归因 |
| 数据质量 | 智能校验 KPI、TOP3 问题卡片、问题明细（行号 + 字段）、问题单元格高亮（Styler）、DQ001；“数据接入与报表识别”标签页保留原上传识别全部功能 |
| 处置跟踪 | 独立页面：处置单列表、新建（关联预警、责任人、时限）、状态机 新建→已确认→处置中→已关闭、处置轨迹、超时升级 |
| 预警通知 | 原预警通知中心：选择预警、填写收件人、邮件预览、发送记录；多渠道推送演练（不发送） |
| 行业对标 | 中国视图：省级财产险赔付率地图与排名、全国车险保费与单均保费走势、地区保费规模、精协基准纯风险保费查询（地区 × 使用性质 × 车辆种类 × 限额）、车均保费代理；每张图表注明口径 |
| AI 风控顾问 | 第 2 批能力不变（流式、引用、数字溯源提示）；健康状态改为状态卡片 |
| 系统设置 | 版本、阈值、邮件服务状态、数据源登记、指标口径 |

- 页脚固定：数据来源、口径声明、内部版本 2026.11。

## 2. 默认数据

- 默认加载 `data/official/brvehins_2011.xlsx`（车险经营监测数据集，SUSEP 公开统计 2011 年）。巴西 27 个州及联邦区保持原地名；金额单位为雷亚尔。旧的 `data/sample/demo_dataset.xlsx` 保留在仓库，不再作为默认，界面不提及。
- 数据来源选项：车险经营监测数据集（SUSEP 2011，默认）／中国行业监测视图／上传机构数据。选择中国视图时，明细类页面自动切换为行业对标，并提示该视图不含机构 × 车型明细。
- 历史趋势只展示本机历史快照，不再生成合成历史。

## 3. 行为保持

- 11.1 修复全部保留：合计行过滤、R008“或”、R011 橙色与三级阈值持久化、`evaluate_frame` 规则流水线与“触发规则”列、首页地图（上传机构数据时）、一键导出 / 打印版、等级中文化。
- 批量通知保持原逻辑：未配置 SMTP 时模拟记录，配置后按正式流程投递；须先预览收件人并确认。
- `AlertLifecycle` 新增只读方法 `list_cases()`，其余后端接口不变。
