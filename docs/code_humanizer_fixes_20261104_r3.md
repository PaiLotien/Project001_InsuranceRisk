## 修改边界

F01–F03 的共享逻辑及 F05 是结构清理。F04、B01、B02 是经用户要求执行的行为修复，结果变化单独测试。
默认配置与现有正常数据的 361 条 Demo 归因结果逐项保持一致。旧代码在零值、缺失或自定义阈值场景的错误结果不作为需要保留的行为。

UploadReadError 用于区分输入文件问题与内部处理错误，继承 ValueError；UI 缓存包装只保留缓存职责。没有新增工厂、注册器或全局报表清单。
公共类型、对象/字典输入、公开导出函数和兼容参数保留；没有为了风格删掉必要的网络错误处理。
