# 数据来源与口径说明

车险智能风控平台（IRDS）内置两套公开数据，**分开展示、互不改名**：

1. **车险经营监测数据集（SUSEP 公开统计，2011 年）**：默认明细层，州 × 车型。
2. **中国行业监测视图**：国家统计局 / 国家金融监督管理总局 / 中国精算师协会公开统计，用于“行业对标”页的宏观与基准视图。

机构自有数据通过侧栏“上传机构数据”接入，仅在本机处理。

---

## 1. 车险经营监测数据集（默认）

| 项目 | 内容 |
|---|---|
| 文件 | `data/official/brvehins_2011.xlsx`（工作表“完整数据集”249 行、“字段来源说明”16 行） |
| 原始数据 | CASdatasets `brvehins1`（1,965,355 份保单），基于巴西保险监管局 SUSEP 的 AUTOSEG 车险统计系统，统计年度 2011 |
| 发布机构 | Superintendência de Seguros Privados（SUSEP，巴西保险监管局）；整理：CASdatasets（Charpentier、Dutang 等） |
| 原始发布页 | https://www2.susep.gov.br/menuestatistica/Autoseg/ （AUTOSEG） |
| CASdatasets 参考页 | https://dutangc.github.io/CASdatasets/reference/brvehins.html |
| 许可 | CASdatasets 以 GPL (≥ 2) 发布；使用时注明 SUSEP AUTOSEG 与 CASdatasets |
| 转换脚本 | 仓库外 `/workspace/irds_datasets/poc/brvehins_to_irds.py`；196 万行原始数据未提交 git |
| 地区 | 27 个州及联邦区，保持巴西真实地名（中文译名）；“全辖”为全国合计；不映射为中国分公司或省份 |
| 车型 | 由车辆组别、车龄、法人标识映射为 8 类：企业车、家用车（车龄 0-2 / 3-7 / 8 年以上）、摩托车（450cc 以上 / 以下）、货车、非营业皮卡；另有“合计”行 |
| 金额单位 | 巴西雷亚尔（BRL）。字段名沿用平台标准“签单保费_万元 / 单均保费_元 / 案均赔款_元” |

### 字段与来源标记

| 字段 | 来源 | 说明 |
|---|---|---|
| 机构、保费占比、签单保费_万元、单均保费_元、累计出险频度、满期赔付率、案均赔款_元、承保车年、赔案件数 | 真实 | 直接由公开数据汇总计算；频度、单均保费以承保车年为分母 |
| 车型 | 真实（映射） | 见上 |
| 预期赔付率 | 模型 | 以州 × 车型 × 驾龄格子拟合频度 Poisson GLM 与案均 Gamma GLM，得到预期赔款，总量校准到实际赔款 |
| 成本率1 | 假设 | 费用率外部参数（家用车 27%、企业车 25%、货车 24%、摩托车 30%、皮卡 27%），**待业务校准** |
| 预期成本率 | 模型 + 假设 | 预期赔付率 + 成本率1 |

### 缺口

- 只有 2011 年一个期间，不生成同比、环比；历史趋势需机构自行导入快照。
- 成本率1 为假设值，预警等级受其影响；正式使用前须由业务确认费用率。
- “满期赔付率”为赔款 ÷ 保费的经验赔付率，非严格满期保费口径。

### 口径（界面已逐处标注）

- **省级为财产险全险种口径，不是车险单独口径**；赔付为“赔付支出”（已付、现金制），赔付率＝财产险赔付支出 ÷ 财产险保费收入，不等于车险满期赔付率。
- **省份数据不含计划单列市**（例如辽宁不含大连、广东不含深圳）。
- 基准纯风险保费为 **2020 版**，仅含第三者责任保险，**已去掉车上人员责任险（人员伤亡类）**；代表行业期望赔付成本，不是实际成交保费。
- 全国车险单均保费＝车险保费 ÷ 车险保单件数，按件而非按车；2024 年起官方表不再列示保单件数。
- 2026 年数据为 1–9 月累计，不与全年直接比较。
- 海南 2024 年财产险简单赔付率 101.8%，为当年各省最高；“可能与 2024 年 9 月超强台风‘摩羯’有关”只作为**待核实注释**，不是定论。

### 缺口

1. 省级没有车险单独口径的保费与赔款；用全国车险占比估算省级车险只能标“估算”。
2. 出险频度、案均赔款在国内公开数据中无法取得（《中国保险年鉴》地方版为付费出版物，未使用）。
3. 精协车损险完整车型表不公开，只用三者险部分。
4. 2019–2024 年 NFRA 月度省级保费为图片表，尚未批量转录。
5. 偿付能力季报样例（PDF）未入库，同业对标暂未上线。
